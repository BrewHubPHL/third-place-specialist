# Oldenburg Eight-Characteristic Audit

**Impact:** HIGH  
**Tags:** oldenburg, audit, third-place-criteria, diagnostics

## When to use

Evaluating any candidate third place—café, garden, station, library, park, digital layer.

## How

1. Score each characteristic: neutral ground, leveller, easy access, regulars, low profile, playful, home away from home, conversation primary.
2. Count passes; Dolley's gardens used 8/8 as authentic third-place threshold.
3. Identify weakest link (usually access, leveller, or conversation primacy).

## Pass threshold

Score ≥6 with **conversation** and **neutral ground** mandatory before calling it a third place.

## Trade-offs

Strict audit excludes useful "club-like" spaces that still build bonding capital.
